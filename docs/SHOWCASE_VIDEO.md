# 60-second showcase recording (shot list)

Record with macOS: **Cmd+Shift+5 → Record Selected Portion**, or QuickTime → File → New Screen
Recording. Use a large browser window with the zoom at 100%, close other tabs and hide the bookmarks
bar. Do one practice run first, so every view below has loaded once.

| Time | Shot | What to do |
|---|---|---|
| 0–6 s | **MAIN workspace** | Hold still: globe rotating, KPI monitor, wire, top news. |
| 6–14 s | **Hormuz** | Type `HORMUZ` + Enter. The globe flies there; the inspector shows the disruption chart and live AIS tankers nearby. |
| 14–22 s | **Tankers** | Zoom into the Gulf of Finland / Baltic; hover a tanker, click it to show its card and track. |
| 22–30 s | **Country** | Click a country (e.g. Saudi Arabia): KPIs, sparklines, crude output, events. |
| 30–38 s | **Panels** | Drag a panel by its header, resize one, maximize one (⤢), press Esc. |
| 38–46 s | **MARKETS tab** | Treasury curve (GC), economic calendar (ECO); type `CL1 COMDTY GP`. |
| 46–54 s | **News** | `N OIL`; hover headlines, then show the WIRE news tab with live tags. |
| 54–60 s | **Close** | Back to MAIN, slow globe rotation; optional title card with the URL. |

Keep the cursor slow and deliberate, and add captions in your editor rather than voice-over. In the
post, link the live site and the GitHub repo.
